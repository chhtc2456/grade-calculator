# Grade Calculator Web App

This is a lightweight, interactive grade calculator built with HTML, CSS, and JavaScript. It helps students track course performance and predict required scores using a built-in what-if simulator.

## 🔧 Features

- Add categories like Homework, Quizzes, Exams with custom weights and scores
- Real-time grade calculation with visual progress bar
- What-If Simulator: Enter desired final grade and exam weight to see required final score
- Color-coded feedback: green for high scores, red for low scores
- Auto-saving via browser `localStorage`
- Clear input buttons for both category and simulator sections
- Responsive UI with light animations

## 🚀 How to Run

1. Download or clone the repo:
   ```
   git clone https://github.com/chhtc2456/grade-calculator.git
   ssh: git@github.com:chhtc2456/grade-calculator.git
   ```
2. Open `grade_calculator.html` in any modern web browser (Chrome, Firefox, Edge).

That's it! No install or backend required — this is a static web app.
